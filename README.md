# Pangea

**Where every world begins.**

Pangea is a project notebook for creators. Each project becomes a book: planned with an AI partner, bound into a table of contents, then drafted, researched, annotated, and revised page by page.

## Status

Private product / invite-only demos. **Not** an open contribution target.

Public prelaunch landing:

**https://newsambellamy.github.io/Hidden-Door-Landing-Page/**

## Local development

```bash
npm install
npm run dev
npm run build
```

## Privacy

- Do not commit API keys, demo passwords, or customer data.
- Cloud sync uses Supabase when signed in.
- The optional demo gate is for walkthroughs only; it is not a substitute for user accounts.
